## Django Admin
The Django Admin Portal is a built-in, auto-generated web interface that allows developers and administrators to manage application data (CRUD operations) directly from the browser.

It is created automatically when you define Django models and enable the admin app.

#### Key Features of Django Admin
- Automatic Model interface
- Authentication and Authorization
- Superuser and staff access
- search, filter and pagination

---

#### Limitations of Django Admin
- Not suitable for public users
- Limited/ UI customization
- Not designed as full frontend
- Performance issues for very large datasets

--- 

#### When to Use Django administrators
- Internal dashborad
- Content Management
- Rapid prototyping
- Managing reference data
